# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-11-02

### Added

- Initial public release of `fluxio-image-editor`.
- Angular standalone `<fluxio-image-editor>` component.
- Secondary entry points for core, Fabric renderer, plugins, and testing utilities.
- Crop, transform, adjustments, effects, filters, text, shapes, drawing, image
  overlay, watermark, persistence, layers, history, templates, and export plugins.
- Interactive documentation app and host integration guides.
