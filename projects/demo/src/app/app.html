Templates

Social / output size presets (`templates.tool`). Some presets include placeholder text/shapes on apply. Unchecked uses the built-in gallery; checked replaces it with a small host demo gallery via `config.templates.gallery`.

Color picker

Eyedropper on color fields (text, shapes, drawing, path, watermark). Requires the `color-picker` plugin — no utilibar chrome.

Other features

These tools have no host knobs beyond plugin inclusion and utilibar visibility above.

  • Adjustments / Effects / Filters — raster preview tools
  • Focus — radial bokeh & tilt-shift
  • Crop mask — shape clip with transparent outside
  • Frame — decorative borders
  • Text / Shapes / Draw / Path — annotation tools
  • Compare — hold/pin original (`compare.original`)
  • History / Layers — inspector panels
  • Persistence — design JSON in Source & session
  • Export — always-on save pipeline
